# Химия · 11 класс

Учебный сайт по химии для 11 класса: конспекты, уравнения реакций, калькуляторы, интерактивная таблица Менделеева и итоговый тест.

## Структура

| Файл | Содержание |
|---|---|
| `index.html` | Главная страница |
| `atom.html` | Строение атома и Периодический закон |
| `structure.html` | Химическая связь, решётки, растворы, диссоциация, гидролиз |
| `reactions.html` | Скорость, равновесие, ОВР, электролиз |
| `inorganic.html` | Металлы и неметаллы, качественные реакции |
| `applied.html` | Химическое производство, экология, полимеры, лекарства |
| `table.html` | Интерактивная таблица Менделеева |
| `quiz.html` | Итоговый тест (40 вопросов) |
| `assets/style.css` | Стили (светлая и тёмная тема) |
| `assets/main.js` | Меню, оглавление, переключатель темы |

Сайт полностью статический: без сборки и внешних библиотек.

## Публикация на GitHub Pages

1. Создайте на GitHub новый **публичный** репозиторий, например `chemistry-11`.
2. Загрузите в него все файлы из этой папки (кнопка **Add file → Upload files**), сохранив папку `assets`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Source: Deploy from a branch**, ветку **main** и папку **/ (root)**. Нажмите **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу:
   `https://<ваш-логин>.github.io/chemistry-11/`

Через командную строку:

```bash
git init
git add .
git commit -m "Сайт по химии 11 класс"
git branch -M main
git remote add origin https://github.com/<ваш-логин>/chemistry-11.git
git push -u origin main
```

## Локальный просмотр

Достаточно открыть `index.html` в браузере.
